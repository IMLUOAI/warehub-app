WAREHUB — Warehouse Management System
Double Sided ISCM LLC
WAREHUB is a browser-based warehouse operations app built for Double Sided ISCM LLC to manage daily shipping label batches, guide packers through bundle fulfillment, and track staff productivity and payroll in real time. The app runs entirely in a single HTML file with no server, no installation, and no external dependencies — just open it in any modern browser and it works.
Every morning, the manager imports the day's shipping label PDF exported from the OMP/WMS system. WAREHUB automatically parses each page of the PDF into individual orders, detects the carrier (GOFO, FedEx, UPS, USPS, SWIFT, and SpeedX), and extracts the tracking number, recipient address, SKU items, shelf location, and weight for every shipment. Orders are then assigned to packers through the Packers tab, either manually via dropdown or automatically distributed round-robin with the Auto-Assign button.
Each staff member — both managers and warehouse packers — is issued a printed credit card-sized ID badge generated directly inside the app, featuring their name, position title, company name, and a scannable Code 128 barcode encoding their unique ID. At the Pack Station, staff clock in by scanning their ID badge with a Bluetooth barcode gun, which logs their start time automatically. They then scan each item's SKU barcode to fulfill their assigned orders one by one — the app checks off each item, flashes green on correct scans, and alerts with a red warning on wrong ones. When all items in an order are packed, the app plays a completion sound and automatically advances to the next order. At the end of the shift, scanning the same ID badge again clocks the packer out and records the session duration.
All time tracking data is available in the Payroll tab, which displays a full time sheet with clock-in and clock-out times, total hours worked, orders completed, and items scanned per person. The manager can export the complete payroll data as a CSV file for manual payroll entry. A live Dashboard tab shows carrier breakdowns, SKU progress, a packer leaderboard, and a full order table. A dedicated Floor Display tab shows a large remaining order count and per-packer live stats, designed to run fullscreen on a shared warehouse monitor so the whole team can track progress throughout the day.
